# אימונים — Workout Log PWA Design

Replaces Apple Notes workout notes. iPhone-only PWA that behaves like a native app, with a look of its own (item 80, updated 2026-11-12).

## Decisions (from grilling, 2026-10-26)

1. **Core flow:** live session + history. Open a routine, go through it live checking off sets; each finished workout lands on a timeline feed. Tap an exercise to see its history.
2. **Per set:** weight + reps, prefilled from last time; usually just tap ✓. Items are either reps-based or time-based (`15 דקות`, `30 שניות`).
3. **Language:** Hebrew UI, full RTL.
4. **Storage:** on device (IndexedDB) + Export/Import backup file. No account, no server.
5. **Set order:** always straight sets — all sets of one exercise, then the next.
6. **Routines:** paste a note → app parses it → user fixes the result; routines also editable in-app (add / reorder / delete exercises).
7. **Timer:** workout clock (elapsed time), plus a rest timer that stays out of sight (item 43, updated 2026-11-03).
8. **Hosting:** public GitHub repo, GitHub Pages, auto-deploy on push to `main`.
9. **Timeline entry (updated 2026-11-04, item 50):** routine, day + date, duration, sets done, plus how many exercises improved (↑) and set new bests (★). Tap → full workout. Other activities show name, day and duration (item 40), plus the location when they have one (items 41 and 50, updated 2026-11-07).
10. **Tabs:** ציר זמן (home, with "התחל אימון") · אימונים (routines; settings/backup inside) · תרגילים (exercise list with history). Item 42 adds יומי as a fourth tab, second in the bar (updated 2026-11-07).
11. **Name:** אימונים. Repo: `workout-log`.
12. **סיכום note (added 2026-10-26):** optional free-text note per workout. Tapping "סיום" opens a "סיכום האימון" sheet with a text box (may be left empty) and "שמירה"; the note can also be added/edited later from the workout's detail page. The detail page shows the full text; the timeline card doesn't show it (updated 2026-11-04, item 50).

13. **One workout at a time (added 2026-10-27):** tapping התחל on a routine while a different workout is in progress shows an action sheet "יש אימון בתהליך" with "המשך את <routine>" (opens the workout in progress) and "ביטול". A new one starts only after the old one is finished or deleted.
14. **Prefill after a type change (added 2026-10-27):** if the last session of an exercise used a different target type (reps vs time) than the routine now has, prefill from the routine's target with no weight, not from that session.

15. **Design pass (added 2026-10-27):** Impeccable (Operate mode) + Apple HIG; HIG wins on conflicts. Native iOS structure with an accent colour as tint, the icon's orange by default (light `#B34E00`, darker than system orange so tinted text meets item 70; dark `#FF9F0A`, updated 2026-11-07; the owner can pick another, item 76, updated 2026-11-09), ✓ stays iOS green, SF system font, light/dark follow the phone. Updated 2026-11-12: the look is now the app's own (item 80), always dark (item 81), with Heebo instead of SF and טורקיז as the default accent (item 82). HIG still wins on behaviour, and ✓ is still green.
16. **Live workout UX (added 2026-10-27, updated 2026-11-03):** ticking the last set of an exercise auto-advances to the next right away (active workouts only, not on the last exercise); weight/reps have −/+ steppers (weight ±1 kg, reps ±1, time ±1 min or ±15 s) and the number can still be tapped to type; the previous session's sets are not shown, since they prefill the sets; a progress bar shows done sets / total sets (skipped exercises excluded).
17. **Timeline + exercises (added 2026-10-27; the weight line replaced 2026-11-13 by item 104):** week headers show "N אימונים · M סטים" (other activities count as workouts, item 40); exercise history pages show a small SVG line of the heaviest weight per session when there are ≥2 weighted sessions.

18. **Post-launch feedback (added 2026-10-28):** decided after the first real session. One branch for all items. Connecting Claude to GitHub is out for now.
19. **Starting weight (added 2026-10-28):** a routine exercise may have a starting weight. It prefills only while the exercise has no history; after that, the last session's weights prefill as before. It is shown in the routine row ("10 חזרות · 20 ק״ג").
20. **Sets per exercise (added 2026-10-28):** an exercise (or pair) may override its section's set count. The override is stored only when it differs from the section, and the row shows "· N סטים".
21. **Tips and exercise notes (added 2026-10-28, updated 2026-11-03):** two kinds of note.
    - A tip (דגשים) on the routine exercise is copied into the workout and always shown under the exercise name.
    - A note ("הערה") belongs to the exercise and carries over from workout to workout until you change or clear it. Each workout copies it from the latest finished workout that has the exercise, even one where it was skipped. (The sets still prefill from the last session with ticked sets.) Renaming an exercise in a workout's "עריכה" gives it the new name's note when that name has one, and otherwise keeps the note it had.
    - Notes written before this change were for the next time only and were not copied into later workouts. Updating the app (database version 8) and importing a backup made before it (backup version 1) copy each exercise's latest note forward into its later workouts, so it carries on from there. Backups now say version 2, and their notes are left as they are.
    - It is shown in a row of its own under the sets (✎, the note, ›; "<name>: …" for each exercise of a pair that has one), during the workout and when editing a finished one. With no note, the row reads "הוספת הערה" (updated 2026-11-12, item 83: with no note it is a link beside "דלג" and "הוספת סט" instead of a row). Tapping it opens "הערה לתרגיל", a sheet with a large text box (updated 2026-11-03). The row keeps the note's line breaks (updated 2026-11-04).
22. **Duplicate routine (added 2026-10-28):** a "שכפול" swipe action creates "<name> (עותק)" with fresh ids and opens it in the editor. "שכפול האימון" in the editor does the same, as the swipe's tap path (item 51, updated 2026-11-04).
23. **Past workouts (added 2026-10-28):**
    - "+" on the timeline, then "אימון קודם" (item 40), opens the past workout form. You choose the routine, date, start time (in the past, on a 24-hour wheel) and duration.
    - The duration is at most 3 hours (the time limit in item 27), and the workout must end by now. Otherwise saving is disabled and a message explains why.
    - The workout is created finished, with sets prefilled from sessions before that date, and opens in edit mode.
24. **Start button (added 2026-10-28):** "התחל אימון", and the "אימון בתהליך" banner during a workout, are pinned at the bottom of the timeline, above the tab bar.
25. **Weight fill-down (added 2026-10-28):** entering a weight on set N also sets it on later unticked sets of that exercise whose weight is empty or still equals set N's previous weight. Weight only.
26. **Auto-advance (added 2026-10-28):** after the last set of an exercise, the workout moves to the next exercise that is neither skipped nor done. If there is none, it stays.
27. **Limits (added 2026-10-28):** weight ≤ 500 kg, reps ≤ 100 (whole), time ≤ 3 h. Typed values are clamped on commit, and "+" is disabled at the max. This applies in the workout and in the routine editor.
28. **Gestures and motion in a workout (added 2026-10-28):**
    - A horizontal swipe on the exercise moves between exercises; skipped ones stay reachable. In RTL, dragging rightward goes to the next exercise. A swipe that starts on a set row swipes that row instead (item 44, updated 2026-11-03).
    - A swipe that starts within 50 px of the swipe-back edge is left to the app's swipe-back (updated 2026-10-29). Item 66 has the rule for every swipe (updated 2026-11-07).
    - Swiping up on the footer opens the exercise list.
    - Changing exercise slides the new card in from the direction of travel. There is no motion under reduce-motion.
29. **Summary mid-workout (added 2026-10-28):** "הוספה לסיכום" in the exercise menu (⋯) edits the workout's summary without finishing. The menu's other actions are in item 51 (updated 2026-11-04).
30. **Overview editing (added 2026-10-28):**
    - In the exercise list, "עריכה" lets you add, remove, reorder and edit exercises of the running workout.
    - "עדכון <routine>" writes the exercises, targets, tips and set counts back to the routine.
    - "שמירה כאימון חדש" saves them as a new routine, and the workout moves to it (updated 2026-11-04, item 51).
    - Starting weights are kept from the routine.
31. **Background photo (added 2026-10-28):** a photo chosen in Settings is shown, dimmed, behind the live-workout screen. It is stored on the phone and not in the backup file.
32. **History export (added 2026-10-28):** "ייצוא היסטוריה" in Settings shares finished workouts as readable text (`.txt`), newest first, in the format of the old notes.
33. **Feedback (added 2026-10-28):** "דיווח על באג / הצעה" in Settings opens a prefilled GitHub issue (labels bug/enhancement) with the device and build date and no workout data. The repo is public, so the issue is too.
34. **Navigation (added 2026-10-28):**
    - The live workout opens under the tab it was started from (`/tabs/timeline/workout/:id` or `/tabs/routines/workout/:id`), with the tab bar hidden, so swiping back reveals the page underneath. Ionic only animates a back step between pages of the same tab (updated 2026-10-29). Old `/workout/:id` and `/tabs/workout/:id` links redirect to the timeline version. Editing a finished workout opened from יומי uses `/tabs/daily/workout/:id` (item 42, updated 2026-11-07).
    - After a workout started from אימונים is finished or deleted, the אימונים tab shows its list again instead of the workout's old screen. "סיום" while editing a finished workout goes back, or to the workout's page when there is nothing to go back to, e.g. after a reload (updated 2026-11-03).
    - Taps are ignored while a page transition is still animating, as in UIKit, but never for more than 1 s per transition (updated 2026-10-29).
    - Swipe-back is the app's own gesture, so the real previous page follows the finger. iOS's built-in edge swipe is blocked for touches that start within 20 px of either edge, except on tap targets (buttons, rows, controls, an overlay's backdrop). Both ran together on a Hebrew iPhone, and iOS's alone flashed the old page. A vertical scroll that starts in that 20 px strip does not scroll (updated 2026-10-29).
35. **Version (added 2026-10-29):** the bottom of Settings shows the version and when it was built ("גרסה 1.2.0 · עודכן 29.10.2026 14:05"), so a test can confirm the phone has the latest deploy. Bug reports include both. The version goes up with every release the user can notice: the minor number for features, the patch number for fixes, and the major number only when the whole app changes how it looks or works, as 2.0.0 did (item 80, added 2026-11-12). Dependency, CI-only and docs-only merges still deploy, with no bump and no "מה חדש" entry (updated 2026-11-07, CI added 2026-11-10). Such a deploy still shows the update bar (item 38), since the app can't tell what changed before downloading it. Why: there is nothing to announce, and the build time still shows the phone has the latest deploy. Tapping the version line opens "מה חדש" with every release (updated 2026-10-30).
36. **Routine order (added 2026-10-29):** each routine has a creation date, set when it is created, duplicated, imported or saved as new from a workout, and never changed by editing. Routines are listed newest first everywhere, and the row shows "נוצר 29.10" (with the year when it is not the current one). Routines from before this change take their last-edited date.
37. **Settings from the timeline (added 2026-10-29):** ⚙️ also sits on ציר זמן, before "+". Settings opens inside the tab it came from, and back returns there.
38. **Updates (added 2026-10-30):**
    - The app checks for a new version when it opens, when it comes back from the background, and every hour while open. It skips the check while offline.
    - A downloaded version waits. A "גרסה חדשה זמינה · עדכון" bar sits above the tab bar, never inside a workout. "עדכון" reloads into the new version. × hides the bar until the app comes back from the background. An ignored update applies the next time the app is fully closed and reopened.
    - After an update, "מה חדש" opens once with every release since the last one this phone saw: "חדש" and "תיקונים" for each. With no release seen before, it shows only the current one. It waits until you leave a workout. The last seen version is kept on the phone and is not in the backup.
39. **Picking an existing exercise (added 2026-10-30):**
    - "הוספת תרגיל", in a workout's "עריכה" and in the routine editor, opens a list with a search box.
    - "+ תרגיל חדש" comes first and works as before: it adds "תרגיל חדש" and opens the editor. With text in the search, it takes that name (item 77, updated 2026-11-09).
    - Then come the names from routines and finished workouts, without "תרגיל חדש". Exercises you've done come first, most recent first, with their last date. Exercises only in routines follow, A–Z. Search matches part of a name.
    - Picking one adds it to that section right away, without the editor. It brings the target and tip from the last finished workout that has it, otherwise from the most recently edited routine. Weight is not copied: in a workout it prefills from history, as for any exercise.
    - Exercises already in the workout or routine stay in the list. A pair's second exercise is still named in the editor.
40. **Other activities (added 2026-10-31):**
    - "+" on the timeline opens a sheet: "אימון קודם" (item 23) or "פעילות אחרת", for training outside the gym (Thai boxing, machine Pilates, a class).
    - An activity is logged once, after the fact: name, date, start time and duration, with the same time rules as item 23. Saving needs a name. There is no schedule or recurring class.
    - The name is free text. Names of earlier activities, most recent first, appear under it as quick picks, filtered by what is typed.
    - Saving closes the form and stays on the timeline.
    - Its card shows the name, day and "N דק׳", plus the location when it has one (items 41 and 50), with no sets and no ↑/★ (updated 2026-11-07). It counts as a workout in the week header and adds no sets.
    - Its detail page shows the overview, "סיכום" and delete. "עריכה" reopens the same form, filled in.
    - Activities never open the live workout and never appear in prefills. In the exercises tab they appear only under their own "פעילויות" tile, never mixed in with the exercises (updated 2026-11-12, item 93). Backups and the history export include them.
41. **Activity location (added 2026-11-03):**
    - The activity form has an optional free-text "מיקום" under the name. Saving still needs only a name.
    - The location is remembered per activity name. When the name matches an earlier activity, tapped from the quick picks or typed in full, the location fills in from the newest one of that name that has a location. Activities left without one are skipped.
    - Updated 2026-11-12 (item 93): the remembered location can also be set on the activity's own page, and it wins over the sessions' locations. Logging an activity with a location, or changing the location of a logged one, sets it again, so the last location typed anywhere is the one that fills in. Editing only the time or name of an old session leaves it alone.
    - A location you typed stays when the name changes. "עריכה" opens with the saved location, and changing the name there keeps it.
    - The card, the detail overview and the history export show it after the minutes ("60 דק׳ · פארק הירקון"). Without a location they look as before.
    - Activities logged before this, on the phone or in a backup file, have no location.
42. **Daily routines (added 2026-11-02, moved to their own tab 2026-11-03, updated 2026-11-03, and 2026-11-13 by item 100):** short drills done every day (posture, mobility), not a gym workout.
    - A fourth tab, "יומי", sits second in the tab bar (ציר זמן · יומי · אימונים · תרגילים). "+" there creates an empty daily routine and opens it in the editor, under the tab. With none, the tab explains what it is for and points at "+".
    - "אימון יומי" is a switch in the routine editor and moves a routine between אימונים (gym routines only) and יומי. A daily routine is never started live: it is left out of "התחל אימון" and "אימון קודם". It needs no exercises.
    - Each daily routine has a colour, from 8 iOS system colours (אדום, כתום, צהוב, ירוק, טורקיז, כחול, סגול, ורוד). A routine that becomes daily without a colour gets the colour the other daily routines use least; one that was daily before keeps its colour. A "צבע" row in the editor (daily routines only) changes it. Daily routines from before this were coloured in the order they were created.
    - Each active daily routine has a card, newest first: its colour dot, its name, its drills ("גשר ישבן 15 · פלאנק 30 שנ׳") and a ✓ (the same check as a set row in a workout) that logs today; a second tap removes it, asking first if its numbers were edited (item 69, updated 2026-11-07). Tapping the rest of the card opens the editor.
    - Updated 2026-11-12 (item 89): the cards are tiles above the tab bar with the month above them, and they have no swipe; archiving is "העברה לארכיון" in the editor, and "בארכיון" is a cell among the tiles. The rest of this bullet describes it as it was.
    - Updated 2026-11-13 (item 100): the routines are rows again, above the month, and the swipe "ארכיון" is back, as this bullet describes, with "בארכיון" as a row under them.
    - Swiping a card offers "ארכיון": the card goes, and its days stay in the calendar. With any archived, a "בארכיון" row at the bottom opens their list; tapping one opens the editor and swiping offers "החזרה". Restoring the last one goes back to יומי. Turning "אימון יומי" off takes a routine out of the archive. The editor of a daily routine also has "העברה לארכיון" or "הוצאה מהארכיון", as the swipes' tap path; it stays on the editor (updated 2026-11-04, item 51).
    - Below the cards, one month calendar (Sunday first) covers every daily routine: each day shows a dot in the colour of each routine done (up to 4), and a grey dot when a gym workout or an activity started that day. Days after today are disabled, and today is ringed. ‹ › move between months, back without limit and forward up to the current month; so does a sideways swipe on the calendar, mirrored for RTL (a swipe to the left goes back), with the new month sliding in from that side (added 2026-11-04). Why: iOS calendars page by swiping, and the buttons stay for VoiceOver and for anyone who doesn't know the swipe. There is no streak or count.
    - With exactly one active daily routine, tapping a day it isn't done on, with no workout or activity, logs it at once (the plan, as ✓ does). Any other tap on a day opens a sheet for it, so a day with a workout can be looked at without logging the routine (updated 2026-11-04). Why: with one routine the sheet offered one choice, so tick, then close, was three steps for a yes-or-no fact; tapping a day never removes a log, which may hold edited numbers (item 69, updated 2026-11-07).
    - The sheet lists the active daily routines, plus archived ones done that day, each with its dot and a ✓ that logs or removes the day, asking first if the numbers were edited (item 69, updated 2026-11-07). A ticked routine is one row with its drills on a second line ("גשר ישבן 3 × 15 · פלאנק 2 × 30 שנ׳") and a chevron; tapping the row shows steppers for each drill's sets and reps (by 1) or seconds (by 5), under the drill's name when there are several. Why: with every drill's lines listed, three ticked routines pushed the day's workouts below the fold of the half sheet. Below them come that day's finished workouts and activities, earliest first, with start time and minutes. Tapping one opens its detail page under יומי, and "עריכה" there edits it under יומי too.
    - The timeline shows gym workouts and other activities, never daily routines or logs (updated 2026-11-07).
    - A log records the routine, the day, and for each drill the sets and the reps or seconds done; ✓ fills in the plan. Changing the routine later doesn't change past logs. Logs from before this were filled from the routine's plan. Logs are not workouts: they never count in the week header, never get ↑/★, never prefill, and never appear in the exercises tab, which also leaves out a daily routine's exercises. The "הוספת תרגיל" picker still offers them, so a drill can be added to a gym routine. The history export leaves them out. Logs of a deleted or no longer daily routine are kept but not shown.
    - Backups include the logs, colours and archive; older backups import with none (colours and drill numbers filled in as on the phone), and a restore replaces them.
43. **Rest timer (added 2026-11-03, updated 2026-11-13 by item 97):**
    - Ticking a set in a running workout starts a rest, and ticking the next set restarts it. Un-ticking leaves it running. The tick that finishes the whole workout starts none and stops one that is running. Editing a finished workout never starts one.
    - It stays out of sight: a ⏱ next to ⋯ is the only sign. Tapping ⏱ shows the time left with −/+ for 5 s, or until tapped again. Updated 2026-11-13 (item 97): the current set's plate also shows the time left.
    - −/+ change the rest by 15 s, including the running one; − is disabled at 15 s. The length is kept on the phone for every workout, starts at 60 s and is not in the backup. The timer itself has no off switch.
    - When the rest ends, a short sound plays and ⏱ turns green until the next tick. The sound is a short notification sound that plays over music from other apps instead of pausing it. It plays only while the app is open (iOS web apps can't vibrate or play in the background), and not when you come back to the app after the rest already ended.
    - The rest is kept on the phone until the next tick, or until the workout is finished, deleted or has nothing left to do (updated 2026-11-04). It stops itself when that happens, whatever caused it, so that a workout ended some other way, such as a backup restore, can't leave a rest ringing. It keeps running when you leave the workout, switch apps or iOS reloads the app, and its sound plays wherever you are in the app. Coming back before it ends still plays the sound on time. After a reload, iOS needs one tap anywhere in the app before it lets the sound play. While a rest runs, the screen stays awake on every tab, not just in the workout, and may lock again once it ends.
    - A 🔊/🔇 button next to −/+ turns the sound off or on. The choice is kept on the phone like the length; ⏱ still turns green with the sound off.
44. **Exercise actions (added 2026-11-03):** "דלג" (or "בטל דילוג") and "הוספת סט" are buttons under the note row. Swiping a set row, as in the routines list, shows "שכפול", which adds an unticked copy right after it, and "מחיקה", which deletes it (a full swipe deletes). In a pair, both act on that exercise's set only. "מחיקה" is not offered on an exercise's only set and asks first when the set is ticked. ⋯ offers the same two actions for the highlighted set (item 51, updated 2026-11-04).
45. **Back to the current exercise (added 2026-11-03):** the current exercise is the first one that is neither skipped nor done (where the workout resumes). When you move off it, a "חזרה לתרגיל הנוכחי" pill above the footer takes you back. It is hidden once everything is done and when editing a finished workout.
46. **Feedback form (added 2026-11-03):** "דיווח על באג / הצעה" comes right after the backup section in Settings and opens on "הצעה". The version line stays at the bottom (item 35).
47. **Exercise header (added 2026-11-03):** the line above the exercise name shows the section and position together ("עיקרי · 3 מתוך 8"), then the name and its tips.
48. **Backup reminder (added 2026-11-03):** a web app can't save to iCloud Drive by itself, so the app reminds you instead.
    - A card at the top of ציר זמן shows when the last backup is at least 7 days (7 × 24 h) old and a workout or activity was logged since. With no backup on record it shows once anything is logged. It reads "הגיבוי האחרון לפני N ימים" or "עוד לא גיבית", and "גיבוי" opens the share sheet with the backup file, as in Settings. It is never a sheet or alert.
    - "Logged since" counts finished workouts and activities: more than at the last backup means something new, whatever times they were given. Daily logs, routine edits and edits to old workouts don't count on their own. Deleting a finished workout or activity also lowers the number stored at the last backup, so with 10 at the backup, deleting 2 and logging 1 still shows the card (updated 2026-11-07). Why: otherwise a new record could hide behind a deleted one and exist nowhere else. Deleting something logged since the last backup can leave the card showing until ×, the safer way to be wrong.
    - A completed share (or download) from the card or Settings counts as a backup; cancelling the share sheet doesn't. Restoring a backup counts as a backup made when that file was exported.
    - × hides the card until another workout or activity is logged.
    - The backup section's footer in Settings ends with "גיבוי אחרון: 29.10.2026 14:05", or "עוד לא בוצע גיבוי".
    - The last backup is kept on the phone and is not in the backup.
49. **Skip moves on (added 2026-11-04):** in a running workout, "דלג" moves straight to the next exercise that is neither skipped nor done, as auto-advance does (item 26). If there is none after it, it stays, and "חזרה לתרגיל הנוכחי" leads to any earlier one. Un-skipping, and skipping while editing a finished workout, stay put. Swiping back undoes an accidental skip. Skipping never starts a rest; a skip that leaves nothing to do stops a running one.
50. **Timeline cards (added 2026-11-04; the date column and stats line updated 2026-11-13 by item 99):** less text, so the timeline is easy to scan (issue #35, PRODUCT.md principle 10).
    - A card starts with a date column: the weekday letter over the day number. There is no month: older week headers show their date range, and השבוע and שבוע שעבר are recent enough not to need one. VoiceOver reads the full date ("יום ב׳ 26.10").
    - The day number is in the accent colour (טורקיז by default since 2026-11-12, item 82) for gym workouts and grey for other activities; the weekday letter is grey for both. Why: you can tell them apart while scrolling, and the stats line still tells them apart without colour.
    - Next to it are the name and one line: "52 דק׳ · 18 סטים · ↑3 ★1" for a gym workout, "60 דק׳ · פארק הירקון" for an activity. ↑ and ★ show how many exercises improved or set a new best, and a count of 0 is left out.
    - The card no longer names the exercises or shows the סיכום. The detail page shows each exercise's ↑ or ★ after its name with the value ("↑ 22 ק״ג"), and the full סיכום. When an exercise appears twice in a workout, only the row holding that best set gets the badge, so the value next to it matches that row's sets and the detail page agrees with the card's count.

## Assumptions (accepted by the user)

1. React + TypeScript + Vite; `vite-plugin-pwa` for offline + Home Screen install.
2. Ionic React forced to iOS mode for native behaviour (large titles, swipe-back, tab bar, action sheets, transitions). The look is the app's own since 2026-11-12 (item 80).
3. IndexedDB via Dexie; request persistent storage. Backup = JSON file via share sheet / Files.
4. Data model: routine → sections (name + set count) → items; an item is one exercise or a pair; target is reps or duration. Exercises are identified by name across routines.
5. Pairs (`A 12 -> B 10`): shown on one screen, alternating within each set, each exercise ticked separately.
6. Prefill: from the last time that exercise was done; first time → reps from routine, and the starting weight if it has one (item 19, updated 2026-11-07), otherwise empty. Weight optional (bodyweight).
7. Units: kg, whatever number is typed.
8. Time items: ticked off with the duration prefilled (editable). No countdown.
9. Progress saved on every tap; closing the app or locking the phone → resume where you left off. Screen kept awake during a workout.
10. Mid-workout: skip an exercise, add/remove a set, discard the workout. Finishing early saves a partial workout.
11. Past workouts can be edited or deleted.
12. ↑ = best set went up in weight or reps vs last time. ★ = heaviest weight ever for that exercise.
